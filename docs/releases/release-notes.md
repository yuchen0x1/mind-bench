# 发布记录

## 0.2.1 · 2026-11-13

MIND BENCH 首个公开版本：在本机组织 AI 模型评测，保留原始回答和评分依据，用同一套题比较多个模型。

- 浏览 203 道带来源与验证状态的原创题目，覆盖 15 类能力；可创建副本、编辑提示词、维护变体和导入外部数据。
- 配置自己的模型 API，组织单题、多模型、分类和稳定性评测；报告会自动刷新，支持停止排队任务。
- 使用规则评分、匿名 AI 裁判与人工复核，并排比较回答，导出 JSON/CSV 与可复现运行清单。
- 运行清单保留提示词、参考答案和量表，后续修改题目不会改变新运行的裁判依据。
- Mock 始终标记为模拟结果，外部粘贴回答单独标记，均不会进入真实模型排行榜。
- 提供 Windows/macOS/Linux 的 Node.js 本地运行方式、Docker 配置，以及包含前后端的发布压缩包。修正 Docker 文档复制规则，增加镜像构建与容器启动检查。
- 项目代码采用 MIT 许可证，README 配有本地实际界面和分步操作说明。

### 下载后运行

下载 `mind-bench-0.2.1.tar.gz`，解压后在该目录执行：

```bash
npm ci --omit=dev
npm start
```

使用 Node.js 24 或更新版本，打开 <http://127.0.0.1:3000>。发布包已包含构建好的界面，无需重新构建；个人数据库在首次启动时创建，不随包分发。

### 使用边界

内置题库为待复核的原创草案，MIND BENCH SCORE 是平台实验性分数，不是人类 IQ 或权威模型榜单。真实供应商联网调用与计费尚未用真实 Key 验证。当前为本机单用户工具，没有公网访问认证或代码执行沙箱。下载校验文件用于检查完整性，不是独立数字签名。

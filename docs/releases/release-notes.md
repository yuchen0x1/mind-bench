# 发布记录

## 0.4.0 · 2026-11-18

- 新增本机已保存会话的回归比较 API 和报告页入口：比较同一题目和模型的分数，输出降幅与质量门禁结果；无可比样本不会误报通过。
- Mock、外部回答、未评分或配置不兼容的运行会明确说明排除原因。当前尚无真实模型回归证据。

## 0.3.1 · 2026-11-17

- 工作台支持按浏览器/系统语言自动选择中文或 English，也可手动切换和持久化。
- 导航、运行状态、设置和更新提示即时更新；题库题面、答案与评测数据保持原文。

## 0.3.0 · 2026-11-16

本版本提升了评测运行的可复现性、数据导出安全性和本地服务的故障恢复能力。

- 随机、综合、稳定性和自定义挑战支持稳定 `seed`；种子会保存到运行清单，方便复现实验题目顺序。
- 服务重启后会自动收敛遗留的运行中会话，避免历史记录永久停留在运行状态。
- 供应商类型、HTTP(S) 地址、凭据和常见云元数据地址在保存、模型发现和调用前统一校验。
- 题库、排行榜和报告 CSV 导出会阻止公式前缀直接进入电子表格；外部数据集导入返回原文 SHA-256。
- 修复题库导出路由误匹配问题；评分配置无效时保留原始回答并返回可审计的空分结果。
- API 增加请求 ID、历史/审计分页信息；运行提示和通知补充辅助技术语义。

### 下载后运行

下载 `mind-bench-0.3.0.tar.gz`，解压后执行：

```bash
npm ci --omit=dev
npm start
```

使用 Node.js 24 或更新版本，打开 <http://127.0.0.1:3000>。发布包包含构建好的界面；个人数据库首次启动时创建，不随包分发。`SHA256SUMS.txt` 用于完整性校验，不是独立数字签名。

### 验证边界

本版本的本地单元/API 测试 57/57 通过，Chromium E2E 8/8 通过，发布包独立校验通过。真实供应商联网调用、跨供应商分数可比性、公网认证和代码执行沙箱仍不在本版本承诺范围内。

## 0.2.1 · 2026-11-13

MIND BENCH 首个公开版本：在本机组织 AI 模型评测，保留原始回答和评分依据，用同一套题比较多个模型。

- 浏览 203 道带来源与验证状态的原创题目，覆盖 15 类能力；可创建副本、编辑提示词、维护变体和导入外部数据。
- 配置自己的模型 API，组织单题、多模型、分类和稳定性评测；报告会自动刷新，支持停止排队任务。
- 使用规则评分、匿名 AI 裁判与人工复核，并排比较回答，导出 JSON/CSV 与可复现运行清单。
- 运行清单保留提示词、参考答案和量表，后续修改题目不会改变新运行的裁判依据。
- Mock 始终标记为模拟结果，外部粘贴回答单独标记，均不会进入真实模型排行榜。
- 提供 Windows/macOS/Linux 的 Node.js 本地运行方式、Docker 配置，以及包含前后端的发布压缩包。修正 Docker 文档复制规则，增加镜像构建与容器启动检查。
- 项目代码采用 MIT 许可证，README 配有本地实际界面和分步操作说明。

### 下载后运行

下载 `mind-bench-0.2.1.tar.gz`，解压后在该目录执行：

```bash
npm ci --omit=dev
npm start
```

使用 Node.js 24 或更新版本，打开 <http://127.0.0.1:3000>。发布包已包含构建好的界面，无需重新构建；个人数据库在首次启动时创建，不随包分发。

### 使用边界

内置题库为待复核的原创草案，MIND BENCH SCORE 是平台实验性分数，不是人类 IQ 或权威模型榜单。真实供应商联网调用与计费尚未用真实 Key 验证。当前为本机单用户工具，没有公网访问认证或代码执行沙箱。下载校验文件用于检查完整性，不是独立数字签名。
